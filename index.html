MlBites

Python, NumPy. A machine learning library, written from scratch.

I wanted to understand the algorithms, so I wrote them myself with a scikit-learn-style interface and only NumPy.

  • Logistic regression, linear regression, KNN, k-means, Gaussian Naive Bayes, and decision trees.
  • I ran each one against scikit-learn on the same data. The results match to within small numerical differences.

github.com/henrynyoike/mlbites

CSV Automation Engine

Python, Streamlit, pandas, scikit-learn, Docker. A web app.

Upload a CSV, see what's wrong with it, fix it, chart it, and download the cleaned file.

  • Shows row and column counts, missing values, and duplicates as soon as a file is uploaded.
  • Removes duplicates and missing values, fills gaps with column means, normalizes numbers, and encodes categories.
  • Draws line, bar, area, scatter, and map charts. The processing code is its own package, and there is a Dockerfile.

github.com/henrynyoike/csv-automation-engine

Homer and Bart Classifier

Python, PyTorch, torchvision. An image classifier.

A small CNN that tells Homer Simpson from Bart Simpson. I trained it for 15 epochs on 215 images and tested it on 53 it had never seen: 77% accuracy, 0.74 precision, 0.67 recall, and an F1-score of 0.70.

github.com/henrynyoike/homer-bart-cnn-classifier

Customer Churn Prediction Pipeline

Python, scikit-learn, YAML. Still in progress.

A pipeline for the Telco dataset of 7,043 customers, split into separate modules for loading, cleaning, validation, and preprocessing. Those parts are finished. Next I'll add the train, validation, and test split, then compare logistic regression with a random forest.

github.com/henrynyoike/customer_churn_pipeline
